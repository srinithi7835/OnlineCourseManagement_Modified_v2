# Online Course Management System

## Modules
- Student: registration, course browsing, enrollment, lessons, quizzes and certificates.
- Instructor: course creation, learner monitoring and assignment management.
- Admin: users, courses, categories, enrollments, payments and certificates.

## Frontend
React.js, React Router, Bootstrap 5 and Bootstrap Icons.

## Backend
Node.js, Express.js and MySQL-ready API structure.

## Data flow
Browser -> React client -> REST API -> MySQL database.

The interface in this version uses simple local demo data so the client can be opened and tested before database configuration.
