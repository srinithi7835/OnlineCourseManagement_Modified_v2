# Online Course Management System

This version keeps the original project folder and file names but uses a different UI, data model presentation and client-side flow.

## Run client
```bash
cd client
npm install
npm start
```
Then open the URL shown by webpack-dev-server.

## Run server
```bash
cd server
npm install
npm start
```
API runs on port 5000 by default.

## Demo login
Any email/password works in the demo client. An email containing `admin` opens the admin dashboard; `teacher` or `instructor` opens the instructor dashboard; other emails open the student dashboard.
